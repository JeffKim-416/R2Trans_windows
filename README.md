# R2Trans

R2Trans는 선택한 텍스트를 단축키로 번역하고 원래 위치에 다시 붙여넣는 Windows 전용 프로그램입니다.

[English README](README_en.md)

## 설치 파일

설치하려면 아래 setup 파일을 실행하세요.

```text
R2TransSetup-0.1.0-win-x64.exe
```

설치 순서:

1. `R2TransSetup-0.1.0-win-x64.exe`를 실행합니다.
2. 설치 마법사의 안내에 따라 설치합니다.
3. 설치가 끝나면 R2Trans를 실행합니다.
4. 설정 창에서 본인의 OpenAI API 키를 입력합니다.
5. 번역 방향, 번역 스타일, 단축키를 확인한 뒤 저장합니다.

## 사용 방법

1. 메모장, 브라우저, 문서 편집기 등 다른 앱에서 번역할 텍스트를 선택합니다.
2. 기본 단축키 `Ctrl + Alt + T`를 누릅니다.
3. 번역 진행 팝업이 표시됩니다.
4. 번역이 끝나면 선택한 텍스트가 번역문으로 바뀝니다.

설정에서 `Confirm Before Replace`를 켜면 텍스트를 바꾸기 전에 번역 결과를 먼저 확인할 수 있습니다.

## 주요 기능

- Windows 전역 단축키로 선택 텍스트 번역
- 한국어, 영어, 일본어, 스페인어, 중국어 번역 지원
- 한국어/영어, 한국어/일본어 자동 감지 번역 지원
- Natural, Formal, Polite, Overly Deferential, Nyang style 번역 스타일 지원
- 번역 결과 확인 후 바꾸기 또는 복사
- 마이크, 시스템 오디오, 또는 둘 다 사용하는 Live Interpreter
- 트레이 아이콘과 로그인 시 자동 실행 옵션

## 제거 방법

Windows 설정의 앱 목록에서 `R2Trans`를 제거하세요.
